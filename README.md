## Module Details

| Module | Topic | Key Contents |
|--------|-------|--------------|
| **I** | Core Java, OOP & Inheritance | - Concepts of OOP and features of Java[cite: 1]<br>- Differences between Java and C++[cite: 1]<br>- Data types, identifiers, operators, arrays, and control statements[cite: 1]<br>- Inheritance: multilevel hierarchy, method overriding, `abstract` and `final` classes[cite: 1]<br>- Runtime polymorphism[cite: 1]<br>- `String` class and lambda expressions[cite: 1]<br>- Difference between Applet and Application[cite: 1] |
| **II** | Packages, Interfaces & Exception Handling | - Defining, implementing, applying, and importing packages and interfaces[cite: 2]<br>- Exception handling fundamentals and types[cite: 2]<br>- Uncaught exceptions and multiple `catch` clauses[cite: 2]<br>- Java's built-in exceptions[cite: 2] |
| **III** | Multithreading, Strings, I/O & Standard Packages | - Creating, implementing, and extending threads[cite: 2]<br>- Thread priorities, synchronization, suspending, resuming, and stopping threads[cite: 2]<br>- Constructors and various string operations[cite: 2]<br>- I/O using the `java.io` package[cite: 2]<br>- Exploring core packages: `java.lang`, `java.util`, `java.util.regex`, etc.[cite: 2] |
| **IV** | Event Handling & AWT | - Event handling mechanism and event model[cite: 2]<br>- Event classes, sources of events, and event listener interfaces[cite: 2]<br>- Abstract Window Toolkit (AWT): working with windows, AWT controls, and layout managers[cite: 2] |
| **V** | Java Annotations & Maven | - Java annotations, their types, annotations library, and custom annotations[cite: 2]<br>- Maven architecture: repositories, plugins, goals, and build lifecycle[cite: 2]<br>- GAV Maven coordinates[cite: 2]<br>- Project Object Model (POM), creating a `pom.xml`, and installing a core Java application[cite: 2] |
