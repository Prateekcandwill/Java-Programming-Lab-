## Module Details

| Module | Topic | Key Contents |
|--------|-------|--------------|
| **I** | Core Java, OOP & Inheritance | - Concepts of OOP and features of Java<br>- Differences between Java and C++<br>- Data types, identifiers, operators, arrays, and control statements<br>- Inheritance: multilevel hierarchy, method overriding, `abstract` and `final` classes<br>- Runtime polymorphism<br>- `String` class and lambda expressions<br>- Difference between Applet and Application |
| **II** | Packages, Interfaces & Exception Handling | - Defining, implementing, applying, and importing packages and interfaces<br>- Exception handling fundamentals and types<br>- Uncaught exceptions and multiple `catch` clauses<br>- Java's built-in exceptions |
| **III** | Multithreading, Strings, I/O & Standard Packages | - Creating, implementing, and extending threads<br>- Thread priorities, synchronization, suspending, resuming, and stopping threads<br>- Constructors and various string operations<br>- I/O using the `java.io` package<br>- Exploring core packages: `java.lang`, `java.util`, `java.util.regex`, etc. |
| **IV** | Event Handling & AWT | - Event handling mechanism and event model<br>- Event classes, sources of events, and event listener interfaces<br>- Abstract Window Toolkit (AWT): working with windows, AWT controls, and layout managers |
| **V** | Java Annotations & Maven | - Java annotations, their types, annotations library, and custom annotations<br>- Maven architecture: repositories, plugins, goals, and build lifecycle<br>- GAV Maven coordinates<br>- Project Object Model (POM), creating a `pom.xml`, and installing a core Java application |
